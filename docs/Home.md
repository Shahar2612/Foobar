
# Social Media - FooBar
Foobar is a social media application inspired by platforms like Facebook. It provides both a web client and an Android app for users to connect and share updates. This WIKI provides an overview of the project, installation instructions, and details about its components.
## Application security
In order to maintain the security of our application, we connect our application to a Bloom Filter data which contains problematic links. 
Every time a user wants to upload a post that contains a link, it will be checked and uploaded only if the link is safe.
